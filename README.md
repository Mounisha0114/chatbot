# 🎓 College Chatbot

An AI-powered College Chatbot developed using Flask and Google's Gemini AI API. The chatbot assists students by answering college-related queries, providing academic information, and offering quick access to campus-related resources through an interactive web interface.

## Features

- AI-powered conversational assistant
- Answers student and academic queries
- User-friendly web interface
- Real-time response generation
- Built using Google Gemini API

## Tech Stack

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript

## Installation

```bash
git clone https://github.com/Mounisha0114/chatbot.git
cd chatbot
pip install -r requirements.txt
python main.py
```
